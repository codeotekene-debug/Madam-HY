# Smart Shop Project Documentation

This root file is an entry point. The detailed source of truth lives under `project/`.

Read in this order:
1. `AGENTS.md`
2. `project/PROJECT.md`
3. `project/STATUS.md`
4. `project/ROADMAP.md`
5. Relevant architecture/module/design documents

Do not use old documentation as proof that a feature is implemented. The current source code and tests are authoritative.

## Documentation Structure
- `project/PROJECT.md` — stable product and architecture overview
- `project/STATUS.md` — current development state
- `project/DECISIONS.md` — durable business/architecture decisions and development constraints
- `project/ROADMAP.md` — implementation roadmap
- `project/architecture/` — technical architecture
- `project/design/` — frontend design rules
- `project/modules/` — module contracts and status
