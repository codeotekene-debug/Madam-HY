# Design System

## Brand
MADAM HY Smart Shop.

## Visual Direction
Green-centered retail interface:
- clean
- modern
- professional
- simple
- retail-focused

## Current Core Tokens
Primary green and related surface/text/border tokens are defined in:
`static/css/core/variables.css`

Current primary token:
`--primary: #057a44`

## Core CSS
- variables.css
- reset.css
- typography.css
- navbar.css
- sidebar.css
- forms.css
- modals.css
- tables.css
- components.css
- responsive.css

## Components
Prefer shared components for:
- buttons
- cards
- forms
- tables
- badges/status pills
- alerts
- modals
- pagination
- loading/empty/error states

## Rule
Do not introduce a new visual system for one page. Reuse shared tokens/components.
